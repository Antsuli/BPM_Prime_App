## Getting Started
1. **Download:** Grab the latest `.apk` from the [Releases section](https://github.com/Antsuli/BPM_Prime_App/releases).
2. **Install:** Enable "Install from unknown sources" on your Android device and install the APK.
3. **Enjoy:** Open the app and start your session!

## Technology
* **Framework:** Android WebView / JavaScript
* **Build System:** Android Studio
